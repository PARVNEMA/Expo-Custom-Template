# Agent Instructions

Project-specific instructions for coding agents live in [`.agents/rules/`](.agents/rules/).

## Working agreement

- Read every applicable rule before changing project files.
- Keep changes focused on the requested task.
- Run the relevant checks before handing work back.
- Do not commit, publish, or modify credentials unless explicitly asked.

## Rule layout

Add focused Markdown files under `.agents/rules/` as the team's conventions are decided. Use descriptive names such as `expo.md`, `testing.md`, or `git.md`.
